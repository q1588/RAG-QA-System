# pytest 测试实践

pytest 是 Python 最流行的测试框架，支持简洁的断言与丰富的插件生态，测试文件以 test_ 开头，测试函数以 test_ 前缀命名。

fixture：用于准备测试环境与数据的可复用装置，通过参数注入测试函数，支持作用域控制（函数级、模块级、会话级）。

参数化：使用 parametrize 装饰器为同一测试提供多组输入，减少重复代码，覆盖边界场景。

monkeypatch：动态替换对象属性或函数，用于模拟外部依赖（如数据库、第三方 API），让测试离线可运行。

隔离：测试使用独立的临时目录与数据库，避免污染开发数据；环境变量在导入应用前设置以保证配置隔离。

断言：pytest 的 assert 语句简洁直观，失败时自动展示实际值与期望值，配合 pytest.approx 处理浮点比较。
