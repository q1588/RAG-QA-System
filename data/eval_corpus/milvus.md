# Milvus 向量数据库

Milvus 是专为向量相似度检索设计的数据库，支持十亿级向量规模，常用于 RAG 检索增强生成、推荐系统、以图搜图等场景。

核心概念：collection 相当于关系数据库中的表；entity 是数据行，包含向量字段与标量字段；partition 用于物理分区，可以提高过滤效率。

度量方式：常见的有 COSINE（余弦相似度）、IP（内积）、L2（欧氏距离）。向量归一化之后 COSINE 与 IP 等价，返回的距离即相似度，便于设定相关性阈值。

索引类型：AUTOINDEX 会自动选择合适的索引；HNSW 适合高召回与低延迟场景，但内存占用较高；IVF 系列在大规模场景下权衡召回率与资源占用。

Milvus Lite：轻量嵌入式版本，单文件即可运行，适合本地开发与测试，通过 MilvusClient 指定本地文件路径即可使用，无需部署独立服务。

部署形态：单机 Standalone 由 etcd（元数据存储）、MinIO（对象存储）与 Milvus 主服务组成，可以使用 Docker Compose 一键编排。

检索过滤：支持在搜索时用表达式按标量字段过滤，例如删除某来源文档的分片时按 source 字段匹配，实现精准管理。
