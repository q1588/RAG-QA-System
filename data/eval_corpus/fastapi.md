# FastAPI 框架基础

FastAPI 是一个基于 Python 类型提示的现代 Web 框架，用于构建高性能 API。它建立在 Starlette（Web 部分）和 Pydantic（数据校验部分）之上，能自动生成 OpenAPI 文档。

路由定义：使用装饰器声明路径与请求方法。例如使用 @app.get 装饰器定义 GET 接口，路径参数会在装饰器里声明，框架自动做类型转换与校验。

请求体校验：通过 Pydantic 模型声明请求结构。FastAPI 根据类型提示自动校验、转换并生成错误响应，非法请求返回 422 校验错误。

依赖注入：使用 Depends 声明依赖。数据库会话、认证用户等公共逻辑抽成依赖函数，FastAPI 自动解析并注入，同时支持依赖嵌套与复用。

异步支持：路由函数声明为 async def 时由事件循环处理，适合 IO 密集任务；普通同步函数会被自动放入线程池执行，两者可以混用。

中间件：通过 add_middleware 注册，用于统一处理跨域（CORS）、日志、限流等横切逻辑。

生命周期：lifespan 上下文管理器在应用启动与关闭时执行初始化和清理，例如建表、加载模型、连接外部服务。

自动文档：访问 /docs 得到 Swagger UI，访问 /redoc 得到 ReDoc，支持在线调试接口。
